Rutas: cómo leer una dirección IP y una ruta de red

Una IP identifica una interfaz dentro de una red. Una tabla de rutas ayuda al equipo a decidir por dónde enviar un paquete hacia su destino. Aprende a leer ambas con una terminal simulada de RINXI.

Una IPv4 tiene una parte de red y otra de equipo

Una dirección IPv4 como 192.168.8.42/24 contiene 32 bits. El prefijo /24 indica que los primeros 24 bits identifican la red; los 8 restantes distinguen direcciones dentro de esa red. En este ejemplo, la dirección pertenece a 192.168.8.0/24.

El prefijo CIDR se escribe después de una barra. Un número más alto representa un bloque menor: /24 cubre más direcciones que /26. La máscara equivalente a /24 es 255.255.255.0.

Leer 192.168.8.42/24: dirección del equipo 192.168.8.42; red 192.168.8.0/24; los equipos conectados a esa red pueden comunicarse directamente según el escenario.

¿Qué información guarda una ruta?

Una entrada de la tabla asocia un prefijo de destino con una acción: enviar directamente por una interfaz o pasar el paquete a una puerta de enlace (siguiente salto). La ruta no describe todo el camino de Internet; indica el próximo paso que debe dar este equipo.

DestinoSiguiente saltoLectura
192.168.8.0/24Directo · eth0Red local conectada
10.20.0.0/16192.168.8.1Red específica vía puerta de enlace
0.0.0.0/0192.168.8.1Ruta por defecto

La ruta más específica

Cuando varias entradas coinciden con una IP de destino, normalmente se elige la que tiene el prefijo más largo, es decir, la red más específica. Para 10.20.4.25 coinciden 10.20.0.0/16 y también la ruta por defecto 0.0.0.0/0. Gana /16. Para una dirección que no coincida con una ruta más concreta, se usa la ruta por defecto.

Tu objetivo en este ejercicio

Consulta la dirección de eth0, examina la tabla y averigua qué ruta usaría el equipo para llegar a 10.20.4.25. Después prueba 203.0.113.10 y compara.

Objetivo esperado: 10.20.4.25 → 10.20.0.0/16 vía 192.168.8.1 por eth0.

Cómo probarlo

Escribe ip addr para encontrar la IPv4 local y el prefijo. Después ejecuta ip route para leer los destinos disponibles. Por último, prueba ip route get 10.20.4.25 y ip route get 203.0.113.10. La terminal mostrará el siguiente salto y la interfaz que corresponden a cada caso.

Si te atascas, escribe pista. Usa help para ver los comandos disponibles.

Esta terminal es completamente simulada: no ejecuta el comando real ip, no inspecciona tu equipo y no envía tráfico a ninguna red. La interfaz y las rutas son un escenario didáctico fijo.

Direcciones de ejemplo y fuentes

192.168.8.0/24 pertenece al espacio privado IPv4. 203.0.113.0/24 está reservado para documentación. El ejemplo 10.20.0.0/16 también es un bloque privado. La notación de prefijo y el criterio de prefijo más largo se describen en RFC 4632; los bloques privados están definidos en RFC 1918 y el bloque de documentación en RFC 5737.
