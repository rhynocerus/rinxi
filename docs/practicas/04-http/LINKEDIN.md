¿Qué ocurre después de que escribes una dirección y pulsas Enter?

El navegador solicita un recurso al servidor. La respuesta que vuelve contiene pistas para entender qué pasó: un código de estado, cabeceras y, muchas veces, el contenido de la página.

En la práctica 04 de RINXI puedes:

• leer una solicitud `GET` sencilla
• identificar `200 OK` y la cabecera `Content-Type`
• observar el HTML que recibiría el navegador
• comparar la respuesta con un `404 Not Found`
